# Flow map — Graduation Clearance (DRAFT, to be corrected by real recon)

**Status:** Guesswork. Written from general knowledge of Nigerian universities, not from
observation at our institution. **Every number below is a placeholder to be replaced with
what actually happens.** Do not show this to a registrar until it is corrected.

**Why this flow first:** it is the one the general rep physically carries, it matches the
"file waits for approval then moves to the next office" description exactly, and every
final-year student experiences it, so the pain is broad and loud.

---

## The paper journey (as currently assumed)

```
                     ┌─────────────────────────┐
                     │  STUDENT collects form  │
                     └───────────┬─────────────┘
                                 v
   ┌─────────────────────────────────────────────────────────┐
   │ 1. Department (HOD / dept officer)                      │
   │    student's file checked: results complete?            │
   │    STALL POINT: file in another office, cannot verify   │
   └───────────┬─────────────────────────────────────────────┘
               v
   ┌─────────────────────────────────────────────────────────┐
   │ 2. Exams & Records                                      │
   │    verify all results, confirm no outstanding courses   │
   │    STALL POINT: result file still with a lecturer       │
   └───────────┬─────────────────────────────────────────────┘
               v
   ┌─────────────────────────────────────────────────────────┐
   │ 3. Bursary                                              │
   │    fees cleared? library fines? hostel?                 │

   └───────────┬─────────────────────────────────────────────┘
               v
   ┌─────────────────────────────────────────────────────────┐
   │ 4. Library / other units (as applicable)                │
```

## What the system would replace

Not the paper. The paper stays. We replace **the unanswered question**:

> "Where is my clearance form right now, and which office has been holding it
> for the last eleven days?"

## Who feels what

| Actor | Pain | Would they use the system? |
|---|---|---|
| Student | No visibility, repeated trips | Yes — they'd scan a code to check |
| Dept officer | Blamed for delays caused elsewhere | Yes — it exonerates them |
| Exams officer | Buried in files, no queue view | Maybe — needs to make their day easier |
| Registry clerk | Extra work if it's manual entry | Depends on the design |
| Registrar | Accountable when it goes wrong publicly | **Yes — our buyer** |

## Deliberately out of scope for v0.1

- Clearance *approval decisions* themselves (that stays human and on paper)
- Payments
- Certificates
- Anything that gives a student a legal document
